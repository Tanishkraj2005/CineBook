# CineBook Frontend Client

Single Page Application (SPA) built with React 19, Vite, and Tailwind CSS.

## Features
- Dynamic movie discovery with genre and language filtering
- Interactive auditorium seat selection with real-time reservation holds
- Multi-step checkout with simulated payment channels (UPI, Card, Cash)
- Digital ticket boarding pass with QR code verification and PDF export
- Customer booking cancellation and self-service management
- Dedicated administrative portal with occupancy reports and ticket gate controls

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
